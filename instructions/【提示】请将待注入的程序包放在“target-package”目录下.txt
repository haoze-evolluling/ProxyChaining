================================================================================
  Clash Verge Rev 跨订阅链式代理独立补丁工具 - 使用说明与目标包放置指引
================================================================================

【重要提示】
请将需要被注入补丁的 Clash Verge Rev 源码或程序包，解压或放置到同级的【target-package】目录下！

--------------------------------------------------------------------------------
一、目录结构说明
--------------------------------------------------------------------------------
本工具仓库首页分为 3 个核心文件夹：

1. patch-tool/       -> [项目程序]
   存放补丁核心注入工具、双击即用的原生可执行程序 (cvr-patch.exe)、Node 脚本及编译构建工具。

2. target-package/   -> [待注入程序包]
   专门用于放置需要被注入的 Clash Verge Rev 程序代码包。补丁程序会自动扫描此目录。

3. instructions/     -> [说明及指引]
   包含本操作说明文件，引导您快速完成补丁的注入与还原。


--------------------------------------------------------------------------------
二、操作步骤（保姆级三步走）
--------------------------------------------------------------------------------

【步骤 1】：放置待注入的程序包
- 将 Clash Verge Rev 的源码包（如从 GitHub 下载的源码压缩包）解压。
- 将解压后的文件夹放入【target-package】目录下。
- 支持以下两种放置方式，补丁工具均可自动穿透识别：
  * 方式 A（直接放置）：
    target-package/
      ├── src/
      ├── src-tauri/
      └── package.json
  * 方式 B（带有一层子文件夹）：
    target-package/
      └── clash-verge-rev-main/
            ├── src/
            ├── src-tauri/
            └── package.json

【步骤 2】：启动补丁程序
- 进入【patch-tool】文件夹。
- 直接双击运行【cvr-patch.exe】（无需配置 Node.js 或任何运行库）。
- 程序将自动扫描定位到 ../target-package 中的 Clash Verge Rev 项目，并显示控制台主菜单：
  [1] 一键注入补丁 (Inject)
  [2] 一键撤销还原 (Restore)
  [3] 检查补丁状态 (Status)
  [4] 查看代码差异 (Diff)
  [5] 导出补丁文件 (Export Patch)
  [6] 重新检测/切换目标目录
  [0] 退出

【步骤 3】：一键注入或撤销
- 在控制台中输入【1】并按回车：程序将自动完成备份并精准打上跨订阅代理链补丁。
- 如需恢复官方原版，随时输入【2】即可无损撤销所有修改，100% 还原。


--------------------------------------------------------------------------------
三、补丁解决的核心问题
--------------------------------------------------------------------------------
1. 解除单组/单订阅限制：支持在一条代理链中混合搭配来自不同订阅、不同分组的节点。
2. 跨订阅节点置灰修复：修复切换订阅/分组后节点变暗（Opacity 0.55）及无法连接的问题。
3. 切换分组保留链条：切换分组浏览其他节点时，不再强行清空已选中的代理链。
4. 全局模式节点解锁：在全局模式链式代理中解除对订阅节点 (provider) 的过滤。
5. 运行时动态链路注入：自动将外部订阅文件中的节点注入 dialer-proxy，确保连接能够真正建立。
